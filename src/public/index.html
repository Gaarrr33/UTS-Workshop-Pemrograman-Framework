Prinsip Keamanan & Penempatan Kunci Kriptografi

  • Zero Plaintext in Transit: Payload berisi data produk & kategori dienkripsi dengan kunci simetris acak AES-256-GCM sebelum dikirim melalui HTTP POST. Plaintext tidak pernah terlihat pada jaringan kabel.
  • RSA-OAEP Key Wrapping: Kunci sesi AES dibungkus menggunakan Public Key Server B (RSA 2048-bit, SHA-256).
  • Isolasi Private Key: Private Key hanya tersimpan secara lokal dan aman di Server B. Server A, database, dan browser client tidak memiliki akses ke Private Key.
  • Integritas Data (GCM Auth Tag): Setiap modifikasi sekecil apapun pada ciphertext akan ditolak saat dekripsi dengan status error integrity failure.
